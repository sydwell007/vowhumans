# Third-party licence review

This report complements `COMMERCIAL-LICENCE-REVIEW.md` and must be rechecked before each production provider activation.

| Dependency / provider | Current use | Commercial action |
| --- | --- | --- |
| Next.js / React / Turborepo / TypeScript | Web platform | Permissive open-source foundations; retain notices and track security updates. |
| Lucide | Interface icons | ISC licence; retain attribution in dependency records. |
| FastAPI / Pydantic | Service scaffolds | Permissive licences; lock and scan production versions. |
| LiveKit | Realtime interface | Confirm hosted/self-hosted terms, TURN costs and privacy terms. |
| OpenAI | Optional realtime/LLM interface | Accept applicable business terms and configure regional/privacy controls. |
| MuseTalk / LivePortrait | Scaffold only | Do not commercialise until model, code, weights and training-data terms are approved. |
| Generated fictional portraits | Included placeholders | Treat as synthetic brand assets; never represent them as real actors. |
| Licensed actors / custom voices | Not included | Require explicit role, channel, territory, commercial-use, expiry and revocation rights. |
| PayFast / Stripe | Interface only | Merchant and webhook activation require separate terms, tax and refund review. |

The repository includes no copyrighted stock photography. Legal review remains required for marketplace, partner, privacy, employment and regulated-industry claims.
