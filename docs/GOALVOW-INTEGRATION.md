# GoalVow Academies integration guide

A GoalVow tutor session binds a published Persona to a course, lesson and approved knowledge-base version. Retrieval results include source citations. The tutor must say when curriculum evidence is missing and must not fabricate course content or expose quiz answer keys.

Presenter projects use the batch path: script, scenes, TTS, avatar render, slide composition, captions, FFmpeg assembly, preview, human approval and export. Supported output contracts are 16:9, 9:16, 1:1, audio-only, transcript, WebVTT/SRT and thumbnail. Actual media generation remains disabled until its providers pass health and consent gates.
