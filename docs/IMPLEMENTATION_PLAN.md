# Commercial expansion implementation plan

## Phase 0 — protect and audit

- Preserve Studio and legacy URLs.
- Add baseline reports, dependency/secret checks and a backend-artifact deployment boundary.

## Phase 1 — commercial web foundation

- Add server-rendered public shell, metadata, sitemap, robots and reusable content architecture.
- Add product, industry, pricing, ROI, gallery, template, integration, customer and conversion routes.

## Phase 2 — authenticated product foundations

- Add organisation portal, onboarding, billing/usage/analytics, security and support workflows.
- Add strict admin route boundary and MFA-readiness disclosure.

## Phase 3 — platform ecosystems

- Add developer, marketplace, partner, Academy, investor, Trust and legal experiences.
- Add central commercial domain logic and API contracts.

## Phase 4 — data and deployment

- Extend PostgreSQL and MariaDB migrations.
- Add authoritative PHP backend package, sanitised Afrihost hand-off and environment/operations guides.

## Phase 5 — hardening

- Run lint, type checking, unit/integration checks, production build, PHP syntax, secret/public exposure, route, link, accessibility and browser verification.
- Activate payment, realtime, GPU, licensed-media and legal functionality only after manual gates pass.
