# Observability and operations

Propagate a correlation/request ID from Vercel through Afrihost and workers. Emit structured logs without prompts, transcripts, secrets, full IPs, payment payloads or biometric source media. Track latency/error rate by route, queue depth, job age, provider errors, webhook retries, usage reconciliation, consent revocation completion and deletion SLA.

Required alerts: web/API outage, elevated 5xx/429, database saturation, failed backups, stale worker heartbeat, render backlog, payment signature failures, unusual API-key use, security incidents and budget thresholds. Maintain runbooks for provider outage, credential rotation, compromised API key, consent revocation, deletion, failed migration and DNS rollback.
