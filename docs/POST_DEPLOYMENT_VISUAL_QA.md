# Post-deployment visual QA

## Required viewport matrix

- 1440 × 900 desktop
- 1280 × 720 laptop
- 1024 × 768 tablet landscape
- 768 × 1024 tablet portrait
- 390 × 844 mobile
- 360 × 800 compact mobile

## Surfaces

1. Digital Human step-eight success: identity name, activation truth, Test Presence, test conversation and Digital Colleague actions.
2. Digital Workforce step-twelve success: environment/version, readiness categories, blockers and next actions.
3. Test Centre: mental model, selectors, run button, result states and history.
4. Operations: provider cards, redacted details, latency/time, deployed colleague states and pause/resume confirmation.
5. Work Queue: task fields, execution gates, cancellation, progress, products and event trail.
6. Work Products: provider/model/source/review evidence.
7. Performance: recorded-only empty states and no fabricated cost.

## Acceptance checks

- Text/background contrast remains readable in every status and disabled state.
- Controls have visible focus, accessible labels and non-colour status text.
- Long names, request IDs and provider details wrap without horizontal page overflow.
- Grids collapse at 1024, 760 and 520 px breakpoints.
- Reduced-motion preference disables decorative movement.
- Loading, empty, blocked, budget-blocked, provider-error and success states are distinguishable.
- No success state claims conversation, video, tool or production execution when its gate/provider is unavailable.
