# Model assets

Model weights are intentionally excluded from Git. Production operators must review the upstream licence, record the source URL and checksum, and run a vetted downloader before enabling a provider. `ENABLE_MUSETALK` and `ENABLE_LIVEPORTRAIT` remain `false` until this review is approved.

The repository contains provider scaffolds, not redistributed weights. Do not add actor media here; upload consented media to the private object store and retain provenance in the identity record.
