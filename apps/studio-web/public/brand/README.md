# VowHumans brand assets

These production assets are derived only from the user-supplied source files in `/public/images`.

- `vowhumans-horizontal-lockup.png`: exact copy of `5_VowHumans Logo and slogan horizontal.png`; used for the public header and footer, Studio, portals, demos, authentication, and error states.
- `vowhumans-mark.png`: transparent-padding crop of `VowHumans Logo only.png`; used where the compact mark is required.
- `vowhumans-icon-192.png`, `vowhumans-icon-512.png`, and `vowhumans-apple-touch-icon.png`: square, transparent app-icon exports of the supplied mark.

No artwork, lettering, colour, glow, or geometry was regenerated.
